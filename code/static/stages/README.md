# 生育期实拍图目录 · static/stages

物候期提醒页的九宫格，每格显示「该作物当前所处生育期」的照片。照片就放在这个目录里。

## 命名规则（改这两个地方必须一致）

```
static/stages/作物名__阶段名.jpg
```

- 分隔符是两个下划线 `__`（单下划线 `_` 也认，但推荐双下划线，避免和阶段名里的斜杠混淆）
- 阶段名 = 图谱里生育期节点名去掉 `作物名-` 前缀的部分
  例如节点 `小麦-灌浆期` → 文件 `小麦__灌浆期.jpg`
- 扩展名支持 `.jpg / .jpeg / .png / .webp`
- 阶段名里的 `/`、空格等非法字符会被替换成 `_`
  例如 `大白菜-莲座期/旺盛生长期` → 文件 `大白菜__莲座期_旺盛生长期.jpg`

## 换图 / 补图

直接把符合命名的图片丢进本目录即可，**不用改代码、不用重启**（每次请求都会检查文件是否存在）。
某张图缺失时，前端会自动退化成按阶段配色的渐变色块，页面不会出错。

想把 AI 生成的图换成自己拍的照片，直接同名覆盖即可。

## 本目录的图是怎么来的

1. 清单：`python scripts/gen_stage_manifest.py` → `data/stage_images.json`（52 个作物 × 287 个阶段组合）
2. 生成：按清单逐张做文生图，原始 PNG 落在 `static/stage_raw/`
3. 归集：`python scripts/collect_stage_images.py` → 裁掉底部水印、转 JPG、按规则命名落到本目录

重新生成某几张：删掉本目录对应文件 → 重跑第 2、3 步。
用 `python scripts/stage_progress.py 6` 可以查看还剩哪些没生成（会自动跳过已完成的）。

## 注意

- 图片是**装饰性配图**，用于让"当前处于哪个时期"一眼可辨；
  它不代表任何具体地块的实拍画面，正式对外材料里请勿当作田间档案使用。
- `static/stage_raw/` 里保留了未裁剪的原始 PNG，作为备份，可随时重新归集。
