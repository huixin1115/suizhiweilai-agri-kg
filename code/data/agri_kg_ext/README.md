# 农业农作物知识图谱数据集

面向**知识图谱可视化展示**与**农业知识问答**构建的农作物领域数据集。

- 版本：v1.0 ｜ 生成日期：2026-09-17
- 节点：**669** 个 ｜ 关系：**3440** 条
- 实体类型：13 类 ｜ 关系类型：21 类 ｜ 问答对：875 条

## 一、文件清单

| 文件 | 说明 |
|---|---|
| `agri_kg.json` | 主数据。含 `meta` / `categories` / `nodes` / `links` 四段，可直接用于 ECharts、D3、Gephi、NetworkX |
| `nodes.csv` | 节点总表：`节点ID, 节点名称, 节点类型, 属性(JSON)` |
| `edges.csv` | 关系总表：`起点ID, 起点名称, 关系类型, 终点ID, 终点名称, 关系属性(JSON)` |
| `neo4j_import.cypher` | Neo4j 导入脚本，`cypher-shell` 直接执行，已建唯一性约束 |
| `agri_kg_dataset.xlsx` | Excel 多表版，按实体类型分表，含使用说明与统计 |
| `qa_pairs.csv` | 农业知识问答对，含问题类型、推理跳数、答案、参考 Cypher |
| `kg_preview.html` | 交互式可视化：左侧图谱 + 右侧检索面板，两者联动 |
| `echarts.min.js` | ECharts 5.5.0 运行库，`kg_preview.html` 的同目录依赖，用于离线查看 |

`kg_preview.html` 与 `echarts.min.js` **必须放在同一目录**：优先加载本地库，缺失时自动回退 CDN。

CSV 均为 `UTF-8 with BOM`，Excel 双击不会乱码。

### 可视化页面：检索 ⇄ 图谱联动

| 操作 | 效果 |
|---|---|
| 右侧检索框输入「小麦」 | 实时列出候选实体（作物 / 别名 / 病虫害 / 肥料 / 土壤 / 产区均可） |

| 单击节点 | 右侧详情区显示属性与全部关联实体 |

| 「1 跳 / 2 跳」按钮 | 切换子图展开深度（2 跳上限 460 节点，超出按度数截断并提示） |
| 双击空白 / Esc / 「返回」 | 逐级返回；「全图」回到 669 节点力导向全景 |
| 点击某条关系柱状条 | 仅保留该关系类型的连线，其余淡出 |

## 三、快速使用

### Python（NetworkX）

```python
import json, networkx as nx
g = json.load(open("agri_kg.json", encoding="utf-8"))
G = nx.DiGraph()
for n in g["nodes"]: G.add_node(n["id"], name=n["name"], label=n["label"])
for l in g["links"]: G.add_edge(l["source"], l["target"], relation=l["relation"])
print(G.number_of_nodes(), G.number_of_edges())
```

### Neo4j

```bash
cat neo4j_import.cypher | cypher-shell -u neo4j -p <password>
```

常用查询：

```cypher
// 番茄的病虫害及其防治药剂
MATCH (c:农作物 {name:'番茄'})-[:易发病虫害]->(p)-[:防治措施]->(t)
RETURN p.name AS 病虫害, collect(t.name) AS 防治措施;

// pH 6.5 左右、年均温 12℃ 的适种作物
MATCH (c:农作物) WHERE c.适宜pH下限 <= 6.5 <= c.适宜pH上限 AND c.适宜温度下限 <= 12 <= c.适宜温度上限
RETURN c.name, c.生育期天数 ORDER BY c.生育期天数;
```

### ECharts

直接读取 `agri_kg.json`，`categories` 字段已配好颜色，可作为 `series.categories` 使用。

## 四、问答对说明

`qa_pairs.csv` 覆盖 5 类问题：

| 问题类型 | 说明 | 示例 |
|---|---|---|
| 属性查询 | 单实体属性 | 水稻适宜的土壤pH范围是多少？ |
| 关系查询 | 一跳关系 | 棉花有哪些常见病虫害？ |
| 反向查询 | 由客体找主体 | 盐碱土适合种什么作物？ |
| 多跳推理 | 两跳及以上 | 水稻得了稻瘟病用什么药？ |
| 条件筛选 / 决策建议 | 多条件组合 | 土壤pH 6.5、年均温 12℃ 适合种什么？ |

每条均附 `参考Cypher`，可直接用于 Text2Cypher / KBQA 模型训练，也可作为 RAG 的检索评测集。

## 五、数据来源与口径说明

- 作物生育期、温光水需求、pH 范围、产量等采用**公开农艺资料的典型值**，用于教学、演示与算法验证。
- 病虫害—防治措施关系遵循"农业防治 + 生物防治优先、化学防治为辅"的绿色防控原则组织。
- 肥料用量、养分吸收量为**生产经验参考区间**，实际生产请以当地测土配方与植保部门指导为准。
- 农药名称仅作知识关联示例，不构成用药推荐；实际使用请遵循农药标签与当地法规。
